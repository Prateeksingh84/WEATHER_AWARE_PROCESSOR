# Requirement Mapping

| Assignment requirement | Implementation / evidence |
|---|---|
| Exact input dataset | `orders.json` — contains the required New York, Mumbai, London, InvalidCity123 orders |
| Current OpenWeatherMap weather | `fetchCurrentWeather()` calls the OpenWeatherMap current-weather endpoint using `q`, `appid`, and `units` |
| Concurrent requests | One async job per order, awaited with `Promise.allSettled(jobs)` |
| Rain/Snow/Extreme -> Delayed | `shouldDelay()` checks exact `weather.main` values `Rain`, `Snow`, `Extreme` |
| Personalized weather apology | `createWeatherAwareApology()` uses customer first name, city, weather condition, description, and patience message |
| InvalidCity123 must not crash | `Promise.allSettled()` isolates each request; rejected result becomes an order-level error |
| Error must be logged | `onError()` writes structured JSON lines to `output/errors.log` |
| API key must not be hardcoded | `OPENWEATHER_API_KEY` is loaded from `.env`; `.env` is gitignored |
| Updated orders JSON | Live `output/orders.updated.json` generated by `npm start` |
| AI Log | `AI_LOG.md` plus `ai-weather-apology-prompt.md` |
| Demo recording | `docs/DEMO_SCRIPT.md` and `docs/SUBMISSION_READY.md` |
| Concurrency proof | Runtime START logs + concurrency unit test |
| Live artifact verification | `npm run verify:live` |
